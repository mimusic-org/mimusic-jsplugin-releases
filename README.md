# 有声书插件发布仓库
本地有声书资源管理与播放：扫描本地有声书目录，提供分类展示、搜索、章节播放、播放进度记忆、收藏、推送到小爱音箱等功能。

## 安装方式

### 自动安装（推荐）

在 Songloft 的官方插件源中搜索"有声书"，点击安装。

### 手动安装

1. 从 [Releases](https://github.com/mimusic-org/mimusic-jsplugin-releases/releases) 下载 `audiobook.jsplugin.zip`
2. 在 Songloft 插件管理页面上传安装

### 前置依赖

- **ffmpeg**：播放 WMA 文件需要宿主环境安装 ffmpeg，否则 WMA 格式无法播放
- （可选）**智能音箱插件**：如需推送到小爱音箱，需额外安装并启用 [miot 插件](https://github.com/songloft-org/songloft-plugin-miot)

## 使用说明

### 目录结构

将有声书文件放入 `/app/audiobook/` 目录：

```
/app/audiobook/
├── 三体/
│   ├── 第001集.mp3
│   ├── 第002集.mp3
│   ├── cover.jpg             # 封面图（可选）
│   └── metadata.json         # 元数据（可选）
├── 明朝那些事儿/
│   ├── 第一章.mp3
│   ├── 第二章.mp3
│   └── folder.jpg
└── 杂集.mp3                  # 根目录音频自动归入"未分类"
```

- 支持的音频格式：mp3、flac、m4a、ogg、wma、wav
- 支持递归子目录（最深 6 层）
- 封面识别优先级：`cover.*` > `folder.*` > `封面.*` > 目录内首个图片

### 基本功能

| 功能 | 说明 |
|------|------|
| 首页列表 | 搜索、分类筛选、收藏过滤、排序 |
| 书籍详情 | 章节列表（支持正序/倒序）、播放进度条、收藏、编辑元数据、刷新 |
| 播放器 | 全屏播放、倍速（0.75x~2.0x）、前进/后退 15 秒、定时关闭 |
| 睡眠定时器 | 时间模式（10/15/30 分钟）或集数模式（1/2/3/5 集后停止） |
| 收藏管理 | 收藏书籍后可在首页筛选仅显示收藏 |
| 最近播放 | 自动记录，方便快速续听（最多 30 条） |
| 元数据编辑 | 编辑书籍名称、描述、分类、标签、作者、封面上传 |
| 重新扫描 | 手动触发全量重新扫描，刷新书籍列表 |

### 推送到音响

> 需要先安装并启用 [miot 插件](https://github.com/songloft-org/songloft-plugin-miot/releases)（v2026.6.16 或更高版本）。

1. 播放有声书后，进入全屏播放器
2. 点击 ☁️音响 按钮
3. 选择要推送的小爱音箱
4. 进入遥控模式，可远程控制播放/暂停、切歌

遥控模式下自动轮询音响播放状态，当前章节结束后自动推送下一章。

### 技术说明

- 运行在 QuickJS 沙盒中，通过 `songloft.*` API 与宿主通信
- 音频通过宿主 Go 层 `http.ServeFile` 直传，支持 Range/206 流式播放
- WMA 文件自动转码为 MP3（128kbps），缓存到 `.cache/transcode/`
- 精确时长由 ffprobe 获取并持久化到播放进度中，本地播放用浏览器 `audio.duration`
- 前端为 Vanilla JS SPA，无框架依赖

### 隐私说明

- 本插件不会收集任何个人数据
- 所有数据存储在本地宿主数据库中
- 推送到小爱音箱需要与小米 IoT 服务通信，仅传递音频 URL
